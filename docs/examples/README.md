# Examples

The following examples are ordered to provide a ground-up understanding of MagnetoPy, starting with how data files are read and parsed, and ending with how to work with magnetometry datasets and perform analyses on them. Descriptions of the data files used in these examples can be found [here](file_descriptions.md) and the files themselves are found in the tests/data directory of MagnetoPy.

Data:

- [Reading a .dat file](reading_dat_file.ipynb)
- [Raw Data and the .rw.dat File](rwdat_file.ipynb)

Experiments:

- [The `MvsH` Experiment Class](mvsh.ipynb)
- [The `ZFC` and `FC` Experiment Classes](zfcfc.ipynb)

Datasets:

- [The MagnetoPy Dataset Class: `Magnetometry`](magnetometry.ipynb)

Analyses:

- [A Simple M vs. H Analysis](mvsh_analysis.ipynb)
- [Quantification of Hysteresis Data using Cauchy Distribution Functions](cauchy.ipynb)
